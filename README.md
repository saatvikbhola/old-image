# Old Image Restoration - Scratch Detection

This is a Streamlit application deployed on Hugging Face Spaces using Docker. It uses a custom U-Net to detect scratches in old photographs and OpenCV to perform image inpainting.

## Running Locally

To run this project locally:

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the Streamlit app:
   ```bash
   streamlit run streamlit_app.py
   ```
